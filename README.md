# Bussescu 🚌

Bus route finder application.

## Project Structure

## Project Structure

- **`frontend/`**: The user interface and client-side logic.
  - **Stack:** Vanilla JS, SCSS.
  - **Tooling:** `live-server` (local hosting), `sass` (CSS compilation).
- **`backend/`**: Reserved for upcoming backend integration and API development.

## How to Run the Frontend

1. Navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server (automatic SCSS compilation + live-server):
   ```bash
   npm run dev
   ```

The application will open automatically in your browser at the address provided by `live-server` (typically `http://127.0.0.1:8080`).
